# SEO Learn Landing Page

صفحة هبوط عربية تعليمية حول SEO وGEO وAEO وAI Search، مبنية بـ HTML وCSS فقط.

## GitHub Pages

من إعدادات المستودع:
1. افتح **Settings → Pages**.
2. اختر **Deploy from a branch**.
3. اختر الفرع **main** والمجلد **/(root)**.
4. احفظ الإعدادات.

بعد النشر ستكون الصفحة على:

https://yousef-almasaed.github.io/seo-learn-landingpage/

## الملفات

- `index.html` — الصفحة والمحتوى والـSEO metadata وJSON-LD.
- `style.css` — التصميم المتجاوب.
- `robots.txt` — تعليمات الزحف.
- `sitemap.xml` — خريطة الموقع.
